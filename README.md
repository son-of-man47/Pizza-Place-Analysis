# Pizza-Place-Analysis
A Case scenario by Tech Crush to analyze a pizza sales data

# Project Overview
This project analyzes sales data from a pizza restaurant to uncover key business insights such as
revenue trends, peak sales hours, top-performing pizzas, and customer purchasing patterns.

# Objectives
• Calculate total revenue and total quantity sold • Identify peak sales hours (Rush Hours) • Analyze
daily and monthly sales trends • Determine best and worst performing pizza types • Examine the
relationship between pizza size, price, and demand

# Dataset Description
The analysis is based on four CSV datasets: orders.csv, order_details.csv, pizzas.csv, and
pizza_types.csv. These datasets were merged to create a unified dataframe for analysis.

# Tools & Libraries Used
Python, Pandas, NumPy, Matplotlib, Seaborn
# Data Processing Steps
• Imported libraries • Loaded CSV files • Merged datasets • Created sales column (quantity × price)
• Converted date column to datetime • Extracted hour, day, and month features

# Key Performance Metrics
• Total Revenue • Total Quantity Sold • Average Pizza PriceAnalysis & Insights
• Identified peak sales hours • Analyzed daily and monthly revenue trends • Determined best and
worst performing pizzas • Evaluated pizza size impact on price and demand

# Business Insights Summary
Sales patterns show clear peak hours and weekday variations. Some pizza types contribute
significantly to overall revenue, while others underperform and may require strategic review.
